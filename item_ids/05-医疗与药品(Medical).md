# 05 - 医疗与药品 ID 列表 (Medical Supplies)

> **使用提示**：医疗用品在 SCUM 中至关重要，特别是消毒绷带和抗生素，能够有效治疗外伤流血与细菌感染。

---

## 🩹 包扎止血用品 (Bandages & Dressings)

| 中文名称 | 物品蓝图 ID (`item_id`) | 说明 |
| :--- | :--- | :--- |
| **军用高级急救止血绷带 (大)** | `Emergency_Bandage_Big` | 止血速度极快，感染率极低，必备顶级急救包 |
| **普通急救绷带 (小)** | `Emergency_Bandage` | 常用止血绷带 |
| **消毒无菌纱布** | `Disinfected_Rag` | 经过酒精消毒的破布条，包扎不引发败血症 |
| **止血带 (Tourniquet)** | `Tourniquet` | C2 / C3 重度肢体喷射状大出血急救止血带 |
| **医用缝合针线包** | `Medical_Suture_Needle` | 缝合深度割裂伤，加速伤口结痂愈合 |

## 💊 药品、抗生素与化学注射剂 (Medication & Chemicals)

| 中文名称 | 物品蓝图 ID (`item_id`) | 作用效果 |
| :--- | :--- | :--- |
| **抗生素药片 (消炎药)** | `Antibiotics` | 治疗 C1~C3 细菌感染、败血症与伤口发炎必用药 |
| **强效止痛药** | `Painkillers` | 快速消除重伤带来的剧烈疼痛与屏幕颤抖 |
| **阿司匹林** | `Aspirin` | 轻度镇痛退烧 |
| **活性炭片** | `ActivatedCharcoal` | 误食毒蘑菇、生肉或脏水中毒后的洗胃解毒药 |
| **复合维生素片** | `Vitamins` | 补充全身体免疫力与多种微量元素 |
| **生理盐水输液袋** | `Saline_Bag` | 严重失血后快速补充血容量 |
| **血袋 (全血输血袋)** | `Blood_Bag` | 输血补血（需血型匹配） |
| **凤凰抗辐射药丸** | `Phoenix_Tears` | 特殊顶级药剂，清除体内辐射与快速回血 |
